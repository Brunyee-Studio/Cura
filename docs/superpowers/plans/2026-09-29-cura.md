# Cura Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Cura — a published GitHub composite action (plus reusable workflow) that runs a scoped, multi-agent Claude Code PR review over OpenCodeReview delegate mode and publishes every finding as an inline comment with a findings-derived score and automatic thread resolution.

**Architecture:** Deterministic TypeScript steps (`node src/cli.ts <step>`) gather context and facts, a Claude Code lead agent plans scopes and dispatches parallel `scope-reviewer` subagents plus a `verifier` (gated in-loop by `cli.ts check`), and a publish step validates, anchors, scores and writes to GitHub via REST + GraphQL. Pure modules hold all logic; I/O modules take injectable clients so everything is unit-testable.

**Tech Stack:** Node 24 (native TypeScript type stripping, no build), TypeScript `tsc --noEmit`, Vitest, oxlint, pnpm, GitHub composite actions, `anthropics/claude-code-action@8ce9314fa9a404564fa7e954cd84f25bcba2b829` (v1.0.236), OpenCodeReview CLI (`alibaba/open-code-review`).

**Spec:** `docs/superpowers/specs/2026-09-29-cura-design.md`

## Global Constraints

- Repo root: `/home/bruny/brunyee-studio/tools/cura`; published as `github.com/Brunyee-Studio/cura`; consumers use `Brunyee-Studio/cura@v1`.
- Node `>=24`; TypeScript must be erasable-only (`erasableSyntaxOnly: true`): no enums, namespaces, parameter properties. Relative imports use the `.ts` extension.
- Zero runtime dependencies: only `node:*` built-ins and global `fetch`. Dev deps: `typescript`, `vitest`, `@types/node`, `oxlint`.
- Scripts, prompts, agent definitions and schemas load from `$GITHUB_ACTION_PATH` (Cura's pinned ref); the consumer's `rules`/`config` load from `origin/<base>` via `git show`.
- Severities `P0 | P1 | P2`; categories `correctness | security | data-loss | performance | contract | convention | test | docs`.
- Markers: summary `<!-- cura:summary -->`, reviewed SHA `<!-- cura:reviewed-sha=<40-hex> -->`, finding `<!-- cura:finding {json} -->` with json `{"v":1,"severity","category","fingerprint"}`.
- Score: 5 none · 4 only P2 · 3 ≥1 P1 no P0 · 2 ≥1 P0 · 1 ≥1 P0 with category `security` or `data-loss`.
- Anchoring cascade: in-hunk line → nearest changed line within **5** lines → file-level comment (file in PR) → unanchorable (job summary only).
- Chunk caps default `max_files_per_scope=12`, `max_lines_per_scope=1500` (added+removed); plan fallback after **2** failed plan checks.
- GitHub retry: 5xx, 429, or 403 with `x-ratelimit-remaining: 0` / `retry-after` → max **4** attempts, backoff 1s, 2s, 4s (or `retry-after`).
- Context dir: `$RUNNER_TEMP/cura`. Guidance files capped at 64 KiB each.
- Commits are conventional (`feat:`, `test:`, `ci:`, `docs:`); GPG-signed (never `--no-gpg-sign`).

## Review Focus

1. **Renamed files and files with `\ No newline at end of file`** — hunk parsing must key hunks by the new path and not count the marker line; pinned in Task 3 (`parses rename and no-newline marker`).
2. **A finding on a deleted file or a line only present on the LEFT side** — must never produce a line comment; `check` reports it and the anchor cascade falls to file-level only if the path exists in head, else unanchorable; pinned in Task 5 (`rejects finding on deleted file`) and Task 6 (`deleted file is unanchorable`).
3. **A PR with zero reviewable files** (only lockfiles/generated) — pipeline must still publish a 5/5 summary without calling Claude with an empty plan failing forever; pinned in Task 4 (`empty reviewable list yields empty plan that passes`) and Task 14 (`skips agent when nothing reviewable`).
4. **Re-run with no new commits (`/cura` on same head)** — must not re-post existing findings as new or duplicate the summary comment; pinned in Task 13 (`re-run on same head edits summary and posts no duplicates`).
5. **A human reply containing the finding marker text** — replies must never be mistaken for Cura threads; only a thread whose *first* comment carries the marker and is authored by the bot counts; pinned in Task 10 (`ignores threads whose root lacks marker or is not bot-authored`).

## Shared Types (`src/types.ts`, Task 1)

```ts
export type Severity = 'P0' | 'P1' | 'P2';
export type Category = 'correctness' | 'security' | 'data-loss' | 'performance' | 'contract' | 'convention' | 'test' | 'docs';
export interface Hunk { start: number; end: number }            // RIGHT-side, inclusive, 1-based
export type HunkMap = Record<string, Hunk[]>;                    // keyed by head path
export interface FileFact { path: string; status: 'added' | 'modified' | 'renamed' | 'deleted'; language: string; added: number; removed: number; dir: string }
export interface Scope { name: string; files: string[]; focus: string; context: string[] }
export interface Plan { scopes: Scope[] }
export interface ConfigScope { name: string; paths: string[]; focus?: string; context?: string[] }
export interface CuraConfig { instructions?: string; scopes?: ConfigScope[]; ignore?: string[]; min_severity?: Severity }
export interface Finding { status: 'new' | 'existing'; thread_id?: string; severity: Severity; category: Category; path: string; line: number; start_line?: number; title: string; body: string; suggestion?: string }
export interface Review {
  summary: string; risk_note: string;
  scopes: { name: string; files: string[]; reviewer_notes: string }[];
  files: { path: string; overview: string }[];
  diagram: string; findings: Finding[];
  resolved: { thread_id: string; note: string }[];
  dismissed: { thread_id: string; reason: string }[];
  discarded: { location: string; candidate: string; reason: string }[];
}
export interface FindingMeta { v: 1; severity: Severity; category: Category; fingerprint: string }
export interface Thread { id: string; commentId: number; url: string; path: string; line: number | null; isResolved: boolean; isOutdated: boolean; body: string; meta: FindingMeta; replies: { author: string; body: string }[] }
export interface CheckError { code: string; message: string; path?: string }
export type Anchor =
  | { kind: 'line'; path: string; line: number; start_line?: number; snapped: boolean }
  | { kind: 'file'; path: string }
  | { kind: 'none'; reason: string };
export interface ReviewFacts { reviewable: string[]; deleted: string[]; hunks: HunkMap; threads: Thread[] }
```
